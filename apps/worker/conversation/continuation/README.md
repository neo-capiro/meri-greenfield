# Supported product SDK continuation

The Claude Agent SDK remains the sole model loop. These modules construct supported options/input/control calls only; they neither run query nor reconstruct its opaque transcript, session codec, model policy or durable control journal. They reuse the canonical public Checkpoint/WorkspaceManifest and root private lifecycle validators. Pinned installed support was inspected in SDK0.3.295 `sdk.d.ts` and `sdk.mjs`; CLI2.1.295 is required by runtime pins. SDK licensing remains the existing adopted package's `SEE LICENSE IN README.md`; no upstream implementation is copied here.

`buildContinuationOptions(continuation,{binding,versions,scopes,request,sourceRequest})` checks the exact private eight-field continuation, canonical checkpoint and workspace hash/path/binding/scopes/object references, runtime versions and original stored request hash. The selected original skill pin, normalized window, original windowRequest and scopes must survive exactly. `continuationContextSha256(request,scopes)` is the agreed canonical digest of `{window,skill,scopes}`. Original windowRequest is additionally compared exactly. The only emitted options are `resume`, optional `resumeSessionAt`, and `forkSession:true/sessionId` for fork. Resume has a new run/attempt/worker and higher same-conversation fence. Fork has an independent conversation/run/attempt/worker/session and independently valid fence; it never retires or mutates the original source run. A null resumeSessionAt means the exact immutable whole-checkpoint transcript prefix restored by the trusted owner, not latest-session lookup. Persisted chain-entry selection, actual opaque bytes/hash readback, fresh workspace, target-only SessionStore writes, current admission and physical retirement remain native-owner gates.

`createConversationInput({requestId,prompt,sessionId?,maxQueued=8})` returns `{prompt,enqueue,close}`. Pass prompt exactly once as query's AsyncIterable input. It uses a bounded Node Readable object stream and the installed SDKUserMessage shape. Initial and steering messages carry exact UUIDs and `client_composed:true`, preserving product text as literal data without SDK slash/file/context expansion. Selected skill/system instructions stay activity-owned. The upstream streamInput implementation closes stdin after its supplied iterable ends, so do not call it repeatedly with singleton steering streams. Keep this input open until the activity's validated terminal result or owned stop, then close. Close discards queued messages and ends the iterator gracefully; it never proves physical process exit.

`createSdkCommandAdapter({binding,contextSha256,input,query,lifetime})` returns `{apply,close}`. Use the existing lifetime and ordinary SDK Query instance. The durable owner must atomically claim the exact PENDING journal command before apply; a Temporal signal is only a wake-up. Commands are validated by root assertWorkerControl, including immutable approval proposal fields for waitForApproval. Steer enqueues the UUID-stamped user message. Pause/wait uses supported Query.interrupt, retains its still_queued receipt (or unknown/null for an older receipt), and closes the owned input/query. Method receivers are preserved. Approval metadata never changes SDK permissions. Every local result remains UNKNOWN with physicalStopProven:false. Duplicate immutable control IDs are never re-dispatched in this adapter; changed intent is refused. This local cache is not a durable replay implementation: DISPATCHING/UNKNOWN across restarts must remain owner journal barriers. Steer APPLIED requires exact SDK user UUID plus durable command hash correlation; terminal result alone is not an acknowledgement. Pause/wait require trusted durable checkpoint publication and separately qualified retirement/admission. SDK diagnostics are not returned as product text.

The root owns integration into existing activity/options and durable command/checkpoint acknowledgements. The control owner owns Postgres/Temporal/replay/current policy. Fake-SDK tests prove these source boundaries only. No actual provider, database, SDK query, task launch, session restoration, source activation, new auth/settings, AWS action or model call was performed. Public0.1.3, original assets and qualification-native source remain unchanged.
