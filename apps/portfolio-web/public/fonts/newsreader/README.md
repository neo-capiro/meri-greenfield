# Newsreader

Self-hosted editorial typeface for saved brief content. Interface text continues
to use Geist. The normal and italic variable fonts load only when requested by a
Newsreader text style. No browser request to a font provider is required.

Unmodified source: [Google Fonts Newsreader](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/newsreader).
Google Fonts metadata identifies Production Type and upstream revision
`1ece6a8bfe5db1a2b90c76cc1fe5d3b2eed5dcf3`. The supplied SIL Open Font License
1.1 is retained in `OFL.txt`. Local filenames omit the bracketed axis names.

| Local file                     | SHA-256                                                          |
| ------------------------------ | ---------------------------------------------------------------- |
| Newsreader-Variable.ttf        | 8a08d13f8a6c0d51be379a60af84f945f65369a67e509ee3c3bdcc421254d7c1 |
| Newsreader-Italic-Variable.ttf | 796668611f80b64d5adf182fde3b6f29ed83b4e7cbec7b96937e84ac01364792 |

Both fonts support weights 200–800 and optical sizes 6–72. CSS uses normal
optical sizing. The component browser harness and Next frontend serve the same
font files and stylesheet.
