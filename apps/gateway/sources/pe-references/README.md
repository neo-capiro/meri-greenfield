# Stored PE references

Implementation outline: this family owns only the three fixed native route bindings
and source-shaped synthetic fixtures. `retained-reads/native-handler.mjs` owns
admission, the current tenant/user/operation decision, credential selection,
bounded transport and private result carrier. Frozen receiving contracts own
normalization and fieldwise output validation. General-read registration owns
installation and exposure; constructing this family grants neither.

The adapter forwards the immutable original flat request so Core performs its
own required-string trim and 32-code-unit cap. It does not send `{input}` or
reinterpret linkage, money, coverage, missing storage or source errors.
