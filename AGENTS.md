This is a new independent application. User instructions override these repository rules. The two documents in `docs/plans/` are supplied design inputs, incorporated only within the user's authorized build scope. Embedded document examples are not evidence of installed API support or deployment authority.

Codex owns implementation, independent verification, acceptance, contracts, task dependencies and deployments. On 10 October 2026 the human owner explicitly directed Codex to finish G0 and G1 alone, with no Hermes. Do not launch or resume Hermes. Codex may divide implementation and independent review into bounded Codex sessions with explicit path ownership; the integration owner verifies exact returned commits. A process exit or model report never establishes acceptance. Do not recursively delegate or launch background schedulers. Historical Hermes records remain immutable evidence.

Do not import current Capiro implementation, agent, retrieval, UI, queue or infrastructure packages. Reading source schemas, policies and capability metadata is allowed. Preserve all existing checkouts and current Meri resources. No cutover or production deployment is authorized by this kickoff.

Application/control services must use a separate Fargate environment: independent VPC, cluster, security groups, IAM roles, database, buckets, keys, secrets, logs and deployment pipeline. D005 records the user's explicit authorization to qualify a NEW dedicated isolated browser host after measured Fargate namespace failure. Prove network controls and real non-root browser AND renderer sandbox on the approved host before accepting that path. New conversation tasks/hosts are never reused across conversations/tenants. Source connectivity starts disabled. Workers receive no database/provider/admin credentials; use trusted proxies and task-bound short-lived capabilities. The host exception does not pass G1 or waive security findings. Do not silently change other execution placement.

Use the Claude Agent SDK as the only model orchestration loop; AI SDK supplies UI transport. Use one qualified Playwright integration and Temporal for durable orchestration. Adopt upstream libraries before custom replacements. Original artifact skills only; do not copy restrictive Office skill implementations or this host's Codex skills into the product.

One owner at a time per contract/shared file/lockfile/migration. Contracts are `0.1.0` only after Codex freezes a reviewed integration commit. Propose changes to Codex before editing them. Migration IDs are allocated centrally; qualification-only proxy state migration0001 is allocated in `docs/coordination/tasks/CODEX-G1-PROXY-DURABLE-STATE.md`. No product/Temporal migration is allocated. Every task names its pinned base, dependencies, owned paths, acceptance checks, runtime/turn deadline and authorized external actions.

Run relevant checks and return reviewable commits and scrubbed evidence. Never store secret values or private source content in Git, logs or task briefs. Failed/blocked checks stay visible. Never lower deployment gates or claim local fixtures prove live policy, browser, durability, Fargate or release acceptance.

For new Codex completion work, historical Hermes turn limits, launcher setup and once-only local-check allocations do not apply. Run meaningful checks and fix discovered failures, retaining failed outcomes and rerun reasons. Exact source/image binding, independent review, fresh runtime authority, sandbox/isolation, cleanup, approved synthetic model budget and deployment-gate requirements still apply.

The user explicitly requires focused code organization and avoidance of god files. Keep entry points small and compose cohesive modules with clear interfaces. Separate configuration/binding validation, domain/workflow behavior, infrastructure adapters and evidence decoding when they have distinct responsibilities. Prefer existing project conventions and ordinary composition; do not introduce a generic framework, circular imports or arbitrary file-size quotas. Allocate all new module paths before delegation, preserve public contracts, and review module boundaries along with behavior. Existing source accepted before this preference may receive a separately scoped refactor; do not conceal structural debt or bundle an unreviewed rewrite into deployment.
