# Action recommendation slice evaluation

This offline tool freezes approved future inputs and scores captured `actions.query` / control-delivery observations. It does not execute tasks, obtain requests or source snapshots, authenticate a supplied approval, authorize a read, call a model or qualify runtime/RG gates. The adopted real corpus remains0 in `evals/retrieval-r2/manifest.json`.

`freezeCorpus(input,{approvalSha256})` covers the complete cases (including gold), source metadata and configuration with a canonical approval-input hash plus a separately supplied operator receipt pin. `verifyCorpus` checks every derived pin. `runnerCases(frozen,{split})` returns executable prompts/requests/context and source/config identity, excluding gold and provenance labels. Related group or identical-origin cases cannot cross splits. Operators remain responsible for identifying paraphrases and semantic near-duplicates; hashes cannot infer those relationships.

`scoreObservations(frozen,{run,observations})` consumes actual retained output and current-read callback traces. `run.bindings` supplies the new producer RunBinding per case, preserving frozen tenant/actor/conversation. Selected client/scope stays fixed. The full returned read envelope hash must match both delivery and read result references. Public UIEvents remain exactly `tool.started` then `tool.completed`, not run completion. Canonical `actions.query` validates the inner recommendation page, complete source metadata and negative-assertion limits. Actual current reader `before_read`/`before_release` callback receipts bind original/current scopes/ref/digest and finite expiry. Receipt integrity is not authentication or live-policy qualification.

Gold `semanticSha256` compares the complete governed envelope after `semanticResult` removes ONLY transport entropy: outer/page run/attempt/worker/fence, request/trace IDs, generatedAt, subject authorizationDecisionId and source retrievedAt. Tenant/actor/conversation, selected subject/scopes, source snapshot/version/proof/asOf/freshness/coverage, exact normalized arguments and every action field remain. Raw canonical validators still check original timestamps and lineage before projection. `replaySha256`, when nonnull, additionally requests exact captured-envelope replay. Source/config/case pins bind independently; gold is never derived from the observed run during scoring. Per-case observation hashes retain exact supplied capture identity for audit.

Every frozen case remains in the denominator. Missing observations, explicit skipped/ineligible outcomes, failed checks and duplicates are separate counts. Foreign or unidentifiable observations remain report diagnostics and make the observation set invalid. A wrong pin fails the case even if marked skipped. Empty cohorts report null rates and cannot yield CLI success for scoring. Real-labelled counts describe supplied metadata only; `qualifiedRealRequests` is always0. Source contracts and deterministic scores cannot authenticate real provenance or approve an RG gate.

Commands: `node evals/task-lookup/cli.mjs --help`. Input/output files are bounded to16MiB; output must be new, with mode0600. Final and parent symlinks are refused, but this CLI is not a filesystem sandbox or hard I/O watchdog. Caller-owned process supervision is still required. No dynamic module/command execution, network, provider call or gold-fed runner occurs.

The broader requirements are unchanged:75 real seeds, at least200 expanded cases, target grouped100/50/50 development/calibration/heldout; original60 real tasks at90% completion/95% factual correctness and100 adversarial/isolation cases; all14skills, complete source inventory, artifact/recovery/UI gates. Original ordinary-answer p95<=8s and broader warm-lookup p95<=15s are distinct, and neither is measured by this scorer's transport capture. Actual measured native/model/config/usage and independent real-data adjudication remain required. Promptfoo/OpenTelemetry remain adopted where execution/trace collection needs them; this deterministic consumer adds no model loop.
