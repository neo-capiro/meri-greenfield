# Durable artifact library implementation outline

Base: frozen history289df116f2d3c7d07e2d6627ef355a65cd0618be. M5 owns storage/service/routes, focused tests and Git; A5 owns private current-origin Core authority and public contract source. Existing history, inspect and download context checks remain unchanged.

The existing publication journal supplies bounded immutable current-head candidates for the current tenant/actor and requested owner/client/conversation scope. Candidates are internal metadata, not authority or downloadable versions. The existing artifact service delegates library discovery to a cohesive library helper, reusing operation lifetime/current authority/retention and the canonical stored-record validator. It scans at most the requested limit of candidates, calls the private current-origin Core owner for each origin, and verifies each releasable head through the existing SQL/publication read owner. Release repeats current origin/retention checks. Only explicit access denial/suppression omits a row; unknown authority/storage failures fail the page.

Cursor binds caller binding/scopes, query and candidate snapshot plus offset; it never grants authority. An empty/short page can have a continuation when denied candidates exhaust the window. No totals or unauthorized metadata are exposed and no complete-history claim is made before the snapshot ends. Per-request/per-phase Core observations may be deduplicated for the same origin; release never reuses admission and receipts preserve their actual check times/expiry.

The route and runtime composition forward only the private authorizeOrigin callback. No model, new run, budget reservation, object bytes, write admission, file store, migration, package version/lock/archive or target action. Matching public receiver preserves original versions and gives no inspect/download brand. Verification covers own cross-conversation success, tenant/actor/client/colleague/revocation denial, suppression, cursor/query/head changes, bounded denied windows, restart and real public control-route mounting. Existing direct-read and history evidence is reused unless behavior changes. Full frontend consumption follows the finalized public contract; this outline is not acceptance.
