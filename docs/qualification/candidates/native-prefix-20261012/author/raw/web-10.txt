L283: ### pg_upgradecluster
L284: 
L285: This program replaces postgresql-dump (a Debian specific program).
L286: 
L287: It is used to migrate a cluster from one major version to another.
L288: 
L289: Usage: `pg_upgradecluster [-v newversion] version name [data_dir]`
L290: 
L291: `-v`: specifies the version to upgrade to; defaults to the newest available version.
