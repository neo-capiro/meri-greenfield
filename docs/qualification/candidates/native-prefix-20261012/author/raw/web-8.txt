L58: libpq is a C library that enables user programs to communicate with the PostgreSQL database server. The server can be on another machine and accessed through TCP/IP. This version of libpq is compatible with servers from PostgreSQL 8.2 or later.
L59: 
L60: This package contains the run-time library, needed by packages using libpq. SSL certificate validation (the sslrootcert=system connection option) requires the ca-certificates package.
