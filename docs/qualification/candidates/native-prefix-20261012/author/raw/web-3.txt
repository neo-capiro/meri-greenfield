L11: PostgreSQL is available in all Debian versions by default. However, Debian "snapshots" a specific version of PostgreSQL that is then supported throughout the lifetime of that Debian version. The PostgreSQL project maintains an cite6†Apt repository with all supported of PostgreSQL available.
L12: ## Included in Distribution
L13: 
L14: Debian includes PostgreSQL by default. To install PostgreSQL on Debian, use the `apt` (or other apt-driving) command:
L15: 
L16:     apt install postgresql
L17: ## PostgreSQL Apt Repository
L18: 
L19: If the version included in your version of Debian is not the one you want, you can use the cite7†PostgreSQL Apt Repository†apt.postgresql.org . This repository will integrate with your normal systems and patch management, and provide automatic updates for all supported versions of PostgreSQL throughout the support cite8†lifetime of PostgreSQL.
L20: 
L21: The PostgreSQL Apt repository supports the current versions of Debian:
L22:   * trixie (13.x)
L23:   * bookworm (12.x)
L24:   * forky (testing)
L25:   * sid (unstable)
L26: 
L27: on the following architectures:
L28: 
L29:   * amd64
L30:   * arm64
L31:   * loong64 (trixie and newer)
L32:   * ppc64el
L33: ### Automated Repository Configuration
L34: 
L35:     sudo apt install -y postgresql-common
L36:     sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh
L37: ### Manual Repository Configuration
L38: 
L39: Import the cite9†repository key :
L40: 
L41:     sudo apt install curl ca-certificates
L42:     sudo install -d /usr/share/postgresql-common/pgdg
L43:     sudo curl -o /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc --fail https://www.postgresql.org/media/keys/ACCC4CF8.asc
L44: Create /etc/apt/sources.list.d/pgdg.sources. The distributions are called codename-pgdg. In the example, replace trixie with the actual distribution you are using. File contents:
L45: 
L46:     Types: deb deb-src
L47:     URIs: https://apt.postgresql.org/pub/repos/apt
L48:     Suites: trixie-pgdg
L49:     Architectures: amd64
L50:     Components: main
L51:     Signed-By: /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc
L52: Install PostgreSQL: (replace "18" by the version you want)
L53: 
L54:     sudo apt update
L55:     sudo apt install postgresql-18
L56: 
L57: For more information about the apt repository, including answers to frequent questions, please see the cite10†PostgreSQL Apt Repository wiki page†wiki.postgresql.org .
