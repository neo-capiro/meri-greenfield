## Outline before implementation

- `corpus.mjs`: ingest closed supplied cases/source snapshots/config and a separately pinned external approval receipt, freeze exact canonical hashes and grouped splits, verify freezes, produce a label-free runner view. Integrity/pinning is not authentication, current authority, permission to obtain inputs or proof of real provenance. Zero corpus is valid and no synthetic case counts as a real request.
- `contracts.mjs`: domain-specific data admission with existing canonical inert snapshot/hash/public schemas and actual `actions.query` source validator. One owner for the existing contracts; no copied schema/validator or new operation registry.
- `score.mjs`: deterministic scoring of actual returned observations against a fixed corpus, exact routes/arguments, source/config/case/run identity, source results/coverage, current authorization decision and public UIEvent/result-reference delivery. Every frozen case is accounted for as passed, failed, missing, skipped or ineligible; malformed/foreign/duplicate observations remain visible. A caller's skipped/ineligible label cannot remove it from the all-case denominator. Held-out gold is withheld from runner projection and score reports.
- `cli.mjs`: fixed local `freeze`, `runner` and `score` commands. Bounded regular JSON files, no link following/output overwrite, no network, dynamic modules, callback executor, provider/model or source calls. Safe imports and explicit CLI exit codes.

API: `freezeCorpus(input,{approvalSha256})`, `verifyCorpus(frozen)`, `runnerCases(frozen,{split})`, `scoreObservations(frozen,observations)`. Exact control delivery/read shape will be joined once the parallel control owner freezes it; no guessed production response or hardcoded success summary. Source objects are immutable supplied metadata, not automatically dereferenced. Approval receipt covers the canonical hash of complete cases (including gold and provenance), snapshots and execution config. Separate operator pin must match that receipt. Never accept an in-document declaration as current authority.

Real traces, source snapshots, approvals, measured budgets and model-quality labels have not been provided. Promptfoo/OpenTelemetry remain adopted tools; no model/trace execution is needed for this offline scorer and no replacement loop is introduced.

Checks: independently frozen source controls, own meaningful failure/identity/denominator/gold/redaction/CLI controls, exact source preservation and raw failures.
