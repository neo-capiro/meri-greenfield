## Application seam to freeze before implementation

`createActionApplication({resolveSession,now,limits})` returns `{handle(Request) -> Promise<Response>}`. POST routes under an explicitly configured fixed application prefix cover `query`, `draft`, `prepare`, `execute`; no public server is started by the library. Body only carries intent: query request, selection/explicit edits, draft or immutable proposal. Tenant/actor/client/run/scope/execution capability/approval decision are never authority supplied by body/header hints. Authorization is an opaque bearer session credential resolved by the trusted callback, and every request resolves current state.

`resolveSession({credential,intent,signal,deadlineMs})` supplies a fresh trusted session: `{lookup,lookupContext,readContext,commandOptions,authorizeExecution,expiresAtMs}`. `lookupContext` follows the canonical lookup owner and owns fresh globally reserved IDs/event slots. `readContext` supplies current binding/scopes/deadline. `commandOptions` follows the canonical command interface with the concrete approval metadata owner. `authorizeExecution({proposal,signal,deadlineMs})` supplies server-owned `{execution,credential}` only; the unchanged executor still checks current approval. Shared construction composes `createActionFollowthrough` and `createCommandToolInterface`; query performs actual lookup plus current-authorized retained read. The exact closed fields/routes/errors must be frozen in the author README and communicated to the local author before dependent implementation. This is a new unactivated HTTP adapter, not a claim of an existing deployed route.

Keep one request lifetime, bounded streaming body acquisition, cancellation and shorter known session expiry. Check expiry again before releasing results. No automatic retry, task effect from draft/prepare, approval generation, hidden rollback claim or borrowed resource disposal. Preserve UNKNOWN and known-stored-but-not-released outcomes without leaking source/private errors. Browser origins are not identity; no permissive CORS is added. The local runnable entry must use loopback only if a listener is included and have a bounded explicit lifetime and cleanup; a one-shot actual Request/Response workflow also qualifies as executable local API evidence.

The author/root API freeze adds required trusted session fields `lookupCredential` and `checkedAtMs`: the browser's opaque application session is not reused as a tool capability, and freshness is checked against the request's resolution phase. Fixed new routes are POST `/api/action-followthrough/{query,draft,prepare,execute}`. Construction has exactly `{resolveSession,now,limits:{maxRequestMs,maxRequestBytes,maxResponseBytes}}`. Successful responses contain the canonical domain result directly; query returns the current-authorized retained read after actual lookup. Errors use a bounded content-free `{error:{code,outcome}}` envelope, preserving actual owner uncertainty/known-stored dispositions. This is an unactivated application wire contract; frozen public0.1 shapes remain unchanged.
