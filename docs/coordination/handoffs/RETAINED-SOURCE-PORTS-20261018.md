## Boundaries and implementation outline

- The canonical gateway dispatch, current authority, measured installation, discovery, budget, and Core authority stay with their existing owners. Source code supplies only task-bound retained family transport and context ports. The composer and startup receiving files belong to task `01a14ed6-4c18-72e3-b12f-d6ebb3bd10e0` and are not edited here. The two memory families belong to task `01a14ed7-35ff-76d2-8d0d-f1b3309fe0c0`.
- `apps/runtime/native-authority/retained-reads/task-ports.mjs` composes the existing retained Core control, delegated transport, and PostgreSQL conversation store for the three operations with published Core routes: `get_research_portfolio`, `get_research_portfolio_changes`, `get_florida_budget_project`. It accepts the pinned Core origin, issuer identity/public key and recipient origins from the caller; the task tuple supplies the current run's pool, binding, verifier, capability and expiry. It returns only the two family configurations and `retainedContextPorts` for the existing `retainedTaskPorts` callback shape. No new authority, endpoint, or credential persistence is introduced.
- `apps/runtime/native-authority/retained-reads/dataset-metadata-port.mjs` supplies the existing pinned global dataset registry to the `dataset-metadata` family inside that same per-task callback. This is a local immutable projection; the canonical dispatcher still owns current authorization, installation and budget.
- `apps/runtime/native-authority/retained-reads/operational-task-ports.mjs` supplies task-bound credentials to the existing `operational-reads` and `action-items-complete` Core HTTP adapters for the client-scoped task/action modes. It pins the accepted run and selected client, acquires a fresh expiry-bearing bearer and service secret per read, and keeps the existing fixed routes and DTO projection.
- `apps/runtime/native-authority/retained-reads/research-evidence-task-port.mjs` supplies a task-bound live bearer to the existing fixed Portfolio evidence GET adapter. It requires the already authorized Portfolio entity subject and exactly the admitted selected-client scope; it does not derive a Portfolio ID or authorize a client-to-Portfolio link.
- The client-evidence and identity-contacts source adapters now accept only the configured operation endpoint and refuse a missing requested endpoint before acquiring credentials or making an HTTP call. This removes sibling-route coupling without guessing a Core route.
- The client-evidence, identity-contacts, mail and meetings passive adapters now prepare an exact `POST /api/clio/tools/<0.2 id>` target and SHA-256 of the UTF-8 `JSON.stringify({input,metadata})` bytes, pass that target and trusted invocation ID to their credential broker, and accept the existing `CapiroMeriRead` token scheme only at the matching configured Core path. A signed call requires that invocation ID and exact target/digest echoes. The canonical Core path or a reserved call refuses Bearer fallback. They canonicalize the exact `{binding,subject,policyRevision,normalizationContext}` correlation, cap it at 8192 decoded bytes before token acquisition, and send its unpadded base64url header only with the signed scheme. These source changes do not themselves issue a task-bound token.
- The control owner remains responsible for a current persisted run and task verification; Core remains responsible for identity, resource currentness, delegated principal issuance and data. A missing binding, configured route/issuer, current credential, current authority, or source result must refuse. Existing dispatch and transport retain deadlines, cancellation, exact operation/request/body binding, output caps and budget settlement.
- Focused synthetic checks cover the new task-port boundaries and the existing retained control/transport paths. The shared receiving owner must merge these slices with other genuine family producers, thread them into startup, include their source paths in measurement, and retain all 76 measured operations. No selected operation may be hidden or revoked to make installation pass.
