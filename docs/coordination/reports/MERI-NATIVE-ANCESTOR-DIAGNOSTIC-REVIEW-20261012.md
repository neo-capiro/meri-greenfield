## Primary API semantics

Python documents Windows `lstat` as opening name-surrogate reparse points themselves, including symlinks and junctions. Other reparse kinds may be resolved by the operating system as for `stat`. Windows stat results expose `st_file_attributes`, with `st_reparse_tag` identifying reparse type when the attribute is set. The candidate refuses a returned reparse attribute even when mode is a directory. That predicate does not prove zero native reparse processing, universal redirection prevention or safety against ancestor replacement races. [Python 3.11 os documentation](https://docs.python.org/3.11/library/os.html#os.lstat).

Microsoft defines `GetDriveTypeW` return 3 as fixed media and 4 as a remote drive; its root path takes the drive root with a trailing separator. A fixed drive result alone says nothing about later reparse ancestors. [GetDriveTypeW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getdrivetypew), [file attribute constants](https://learn.microsoft.com/en-us/windows/win32/fileio/file-attribute-constants).
