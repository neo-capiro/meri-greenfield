## Junction-target and Python startup pitfalls

A known direct target may be considered **only as a new candidate identity**.
Do not pass a resolved spelling back as proof that the original junction was
ordinary. Do not normalize away the rejected component, change its attributes,
remove the junction, create a new drive mapping/alias, or replace lstat with stat.
The proposed target's own path may contain another junction, mount point or
application alias; each ancestor and the executable need independent checks.
UNC/device/extended namespace spellings are not automatically acceptable merely
because an API returns them. The unchanged canonical local-path checks govern.

Launching a different spelling does not prove that `sys.base_prefix` changes to
it. Python computes the base installation during startup; virtual-environment and
path configuration can affect its relationship to the executable. Python's
Windows documentation describes `pyvenv.cfg`, registry paths, installation ZIPs
and `._pth` configuration. Measure actual identities; do not edit those files or
set environment variables to make the output match. [Python base-prefix semantics](https://docs.python.org/3.11/library/sys.html#sys.base_prefix),
[Windows module discovery](https://docs.python.org/3.11/using/windows.html#finding-modules).

`-I` removes user/script path contributions and ignores Python environment
variables; `-S` suppresses site initialization; `-B` prevents bytecode writes.
These flags do not establish a complete executable closure or prove no existing
bytecode reads. Capture explicitly excludes existing bytecode, installation ZIPs,
non-Python data, startup configuration, outside native dependencies, OS binaries
and ACLs. Keep those limits visible. [Python command-line semantics](https://docs.python.org/3.11/using/cmdline.html).

Python.org supplies Python3.11.15 as a source-only security release, with no
Windows binary installer. An existing Windows3.11.15 installation therefore
needs its actual distributor/build provenance; a version string does not prove
an official installer or a supported secured binary. This fact is not a proposal
to downgrade to an older binary release, build Python or change the pinned
runtime. [Python3.11.15 release](https://www.python.org/downloads/release/python-31115/).
