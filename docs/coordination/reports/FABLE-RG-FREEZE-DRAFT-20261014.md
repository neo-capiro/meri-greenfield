# RG-01 to RG-09 and RG-12: definitions, denominators and cohorts to freeze before acceptance (draft for dot, slice 8)

Base `c6053e24b465be677cc5980533009b4aab03beab` (PR86). Author: Fable. Status: PROPOSAL, nothing measured. HANDOFF §10 requires the RG-01 to RG-09 and RG-12 definitions, denominators and cohorts to be frozen before acceptance. This draft turns each ledger row of `docs/coordination/r2/gates.json` (sheet "Qualification", plan `43f9be7c…`, workbook `3d281d7a…`, source commit `fd8765ec…`) into a measurable definition that the existing source can be held to, names the fixture inputs each gate needs from its owner, and says which binding must exist before the gate can run at all. The ledger targets, requirement links and "blocks core release" dispositions are quoted, not changed. RG-10 and RG-11 stay DISABLED_OPTIONAL with their own frozen criteria owed separately and are not drafted here.

Shared conventions proposed for every gate:

- Denominator: the frozen, versioned case set named in the gate, counted after exclusion of cases the owner marks invalid before the run; a case cannot be excluded after a run has started. Every excluded case is listed with its reason in the run receipt.
- Pass/fail per case is decided by a labelled oracle supplied before the run; the executor does not grade its own output. Model-produced free text is scored only against labels, never by a model judge unless RG-11 is separately qualified.
- Cohort: a run is one `(image digest, config digest, catalog version 0.2.15, skill manifest set, fixture set version)` tuple. Results from different tuples are never summed.
- Receipt: for each case the trace of HANDOFF R-10 (subject/window, invocation, candidates, arguments, source statuses, evidence, calls, p50/p95 latency), retained whether the case passed or failed.
- Preconditions: the live or image-qualified bindings named per gate. Until they exist the gate is UNRUN; a local fixture run with scripted sources is labelled `local-artifact` and never promoted to the gate's result.

What this draft does not decide:

- The 75-request seed and the 200-case set do not exist in the repository; without them RG-01, RG-03, RG-05 and RG-09 have no denominator. Owner: QA.
- The 30-second revocation propagation deadline of RG-07 is the handoff's target; the number to freeze before G3 is dot's call.
- Whether the ordinary-answer 8-second cohort "still applies" (HANDOFF §10) is a product decision; this draft retains it as reported.

Freeze procedure proposed: dot records ACCEPT or edits per row; the accepted table is copied into `docs/coordination/r2/` as a new ledger file with its own hash, and `scripts/qualification/r2-reconciliation/reconcile.mjs` gains a check that the frozen definitions reference only gate IDs, requirement IDs and skill IDs that exist. No gate is measured by freezing it.
