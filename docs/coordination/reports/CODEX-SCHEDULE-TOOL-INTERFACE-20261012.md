This is source completion of this interface, not enabled tools or runtime acceptance.

The model supplies actual instructions, complete scheduling choices, a destination reference and requested cost/runtime/retry ceilings. Pending review discloses the normalized instruction, actual target projection (including owner/scopes/destination/budgets), complete requested scheduling policy or cancellation choice, and the complete private intent digest. It omits workflow/template internals. The tool computes the exact instruction digest into create/update intents before hashing; matching a claimed resolver hash alone is insufficient. Public approval fields must bind that full private intent, never only the review view. The optional private intent field preserves earlier lifecycle callers; cancellation forbids it. The current task/template resolver and future workflow still have to establish and implement the instruction mapping—this hash is not evidence of that execution.

Pending proposals do not invoke mutation. List results preserve owned rows even when Temporal inspection is unavailable, full capped inspection windows and bounded original-run summaries. Exact projection/Temporal identity, timestamp wire values, coverage counts and original-run references are correlated. History remains incomplete; original run identity is not verification of the current retry. Output filtering does not imply the SDK did not retrieve/decode upstream workflow fields.

Failures retain `UNKNOWN` or `ACKNOWLEDGED_NOT_RELEASED` where an effect may already have occurred. Messages are sanitized. No failure authorizes automatic retry; the existing durable owner remains authoritative. A 60-second local call bound is a resource limit, not a schedule execution budget. The accepted SDK limitations remain: no SDK update CAS, connection retries can produce multiple wire attempts, encoding/external storage may outlive local cancellation, and cancellation acknowledgements do not prove physical stop.

The only accepted-source amendments are the approved intent-validation extraction and optional instruction digest. Original predicates and approval checks are preserved; multiple-invalid-input diagnostic priority can differ because intent configuration is checked before approval. The original 50 lifecycle tests are byte-identical and pass. No public Command enum or approval policy changed.
