## Supported CLI mechanism

A dedicated fixed config selected through `AWS_CONFIG_FILE`, containing `[profile capiro-dev]` and this setting, can avoid changing the global file. Authentication dependencies of that profile must remain explicitly preserved and independently verified; a minimal config is not universally equivalent for SSO/assume-role profiles. No global config or credentials were read/copied/edited by this research. [Official configuration documentation](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-files.html#cli-configure-files-settings).

The installed `awscli/topics/config-vars.rst` independently lists the setting, Wire/ISO modes, and N/A environment/CLI columns. Current upstream `awscli/customizations/timestampformat.py` installs an identity timestamp parser for Wire; its default ISO parser calls `parse_timestamp(value).isoformat()`. Consequently ISO output can have an offset and six fractional digits, or no fractional part when microseconds are zero. Wire preserves the modeled service timestamp value rather than applying datetime rendering. [Primary formatter source](https://raw.githubusercontent.com/aws/aws-cli/v2/awscli/customizations/timestampformat.py).

The local Step Functions service model declares history `timestamp` as a timestamp and uses the JSON protocol; the official GetExecutionHistory response syntax and example use numeric seconds.
