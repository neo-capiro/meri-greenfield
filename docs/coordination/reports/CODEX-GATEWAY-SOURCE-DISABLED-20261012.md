## Implemented boundaries

`catalog/runtime-catalog.mjs` validates and freezes the actual catalog, snapshots trusted handler bindings and resolves only enabled/qualified read operations with a matching handler hash. It calls the catalog owner's agreed private `resolveOperationContract({id,version})` interface; there is no copied operation registry or guessed validator-name lookup. The resolved descriptor must match the frozen catalog. It never dynamically imports a request-supplied module.

`authorization/current-tool-authority.mjs` composes mandatory trusted ports for opaque capability verification, fresh run/fence state, business policy and source policy. Port responses are bounded raw JSON strings, checked against frozen `0.1` capability/run/decision shapes and the private R2 subject rules. Stable actor/tenant/run/fence, policy revision, scope lineage, required grant labels, exact required source set, expiry and decision timestamps must agree. The run is reread after policy awaits. These consistency checks do not implement signatures, Clerk, actual membership/client/memory/mailbox walls, authentic task admission or authoritative grant storage; the trusted ports must establish those facts independently.

`dispatch/dispatch-lifetime.mjs` validates the absolute deadline before timer/controller allocation, owns cancellation/listener/timer cleanup, only shrinks deadlines and tracks unsettled work. Abort/timeout never proves physical stop. Uncertain budget reservations receive a separately bounded uncertainty write; no refund, budget reset or retry is implemented.

`dispatch/operation-result.mjs` accepts only bounded primitive JSON strings at external data boundaries. Objects/proxies/getters/toJSON are rejected without inspection. Parsed argument authority fields are rejected. Result release requires both binding and subject to match the trusted execution context. Canonical raw federal/data producer outputs lack these lineage guarantees and therefore remain intentionally unreleasable. No public-only exception, operation allowlist, shared DTO amendment or common EvidenceEnvelope is invented. Safe errors use immutable private WeakMap codes: even a modified owned Error.message or thrown proxy cannot supply content to the reported error.

`dispatch/tool-dispatch.mjs` is one tool-call coordinator. It verifies requested operation identity, obtains fresh identity and immediately shrinks its lifetime to the original run/capability deadline before normalization or business/source-policy awaits, hashes the default-materialized input, checks full authority before reservation and effect, validates raw output with the canonical family callback, and rechecks authority before and after resource settlement before releasing a result. Reservations and settlements require matching explicit acknowledgements. Any unresolved post-reservation failure is marked uncertain; no source/command/model loop is added. Discovery is deliberately empty until a separately qualified discovery-grant contract exists.

`index.mjs` is the production composition entry: source-disabled is hardwired, handlers are not configurable, and an activation override is rejected. Construction/import creates no listener, connection, credential, database client, timer or source request. The actual base catalog has **three pending/unimplemented/null-handler mail descriptors**, so it exposes zero tools and makes zero authority/budget/source calls. The other author's 13-operation catalog/resolver source is not frozen in this base; claiming all 13 were integrated here would be incorrect.
