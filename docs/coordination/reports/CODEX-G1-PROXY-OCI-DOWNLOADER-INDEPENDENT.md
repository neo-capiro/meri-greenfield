## Source assessment

Fresh output and non-link ancestors plus a 2GiB free floor precede an exclusive consumed marker and any transport initialization. No resume/retry/reuse or inventory invocation is supplied. These are trusted-filesystem checks, not atomic guarantees against hostile local replacement.

The standard-library opener disables ambient proxy handling and automatic redirects. Every manually attempted URL requires HTTPS, port 443/default, one of the two literal hosts, and no userinfo or fragment. Default TLS certificate and hostname checks are asserted. Every redirect strips Authorization, including same-host redirects; a maximum of four request attempts bounds a chain. Receipts record only status and host. The anonymous pull token stays in memory; its raw body, bearer, signed redirect URL and query strings are not written or printed. A token response length/hash receipt is deliberately retained. Default TLS does not independently qualify the trust store: the external supervisor must clear SSL/proxy overrides and bind the replacement runtime environment before admission.

Each worker checks optional Content-Length against the exact descriptor, refuses nonidentity Content-Encoding, streams at most 64KiB per read, counts actual received bytes and checks size/SHA. A possible one-byte overflow is counted before refusal. It retains the original partial and writes an exclusive canonical copy with an independent streamed size/hash check. Successful storage is deliberately double the compressed footprint: 802,537,076 bytes plus small receipts, below the initial 2GiB free floor. Disk availability can change; failures remain failures. No tar extraction or executable placement occurs here.

Two workers are submitted at most. A worker failure latches stop; the coordinator closes owned responses, cancels queued work and joins owned workers. Worker close errors set stop and prevent the final success check. Success requires 23 completions, exact aggregate received bytes, all 23 canonical compressed posthashes, and fresh plan/manifest/config/source rebinds. Partial output and consumed marker remain on failure. There is no automatic transport retry, process launcher, AWS or provider operation.

The 1200-second whole operation, 120-second blob and 20-second socket limits are **cooperative**, not a physical end-to-end guarantee. DNS, SSL, filesystem and `shutdown(wait=True)` may stall; response closure is not proof of thread exit.
