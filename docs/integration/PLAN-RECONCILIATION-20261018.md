## 1. Status vocabulary

The remaining plan's states (§3): **inventory** · **source** (code at an exact commit, local evidence only) · **integrated** (received on the coherent branch, combined affected checks pass) · **qualified** (exact image/native runtime/DB/SDK path exercised) · **deployed** · **live-verified** (real authenticated user exercised the flow) · **blocked** (with the missing dependency and owner) · **deferred** (explicit approved disposition). Neo's words map: implemented = source, integrated = integrated, tested live = live-verified, missing = blocked/absent.

What is live today: runtime **N17 `4172e474`**, Core **rev 2 `ade7fc88`**, frontend **rev 17 `4ea553fe`** — the first-chat cohort. **Nothing from the three integration branches (meri-greenfield #145, capiro-backend #84, capiro-frontend #92) is deployed**, so every "integrated" row below is at most *source/integrated*; "live-verified" refers only to the older cohort.
