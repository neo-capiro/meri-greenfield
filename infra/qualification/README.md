# Isolated runtime qualification infrastructure

Codex-owned CDK application. `node infra/qualification/app.mjs` synthesizes two NEW stacks for approved account 967807252336/us-east-1. This is a bounded synthetic qualification environment, not G2 foundation or a release. No Capiro VPC, stack, role, database, secret, bucket or load balancer is imported or granted. Live sources stay disabled.

The build stack has a new encrypted/versioned input/evidence bucket, immutable encrypted ECR repository, narrowly scoped CodeBuild role, log group and key. One trusted build at a time, maximum30 minutes. Privileged Docker belongs only to this trusted image builder; Fargate remains unprivileged. Upload only an accepted source archive with SHA/object version recorded, override IMAGE_TAG with that exact40-character commit, and capture the build ID, source version, logs and resulting digest. A failed build cannot push an accepted candidate.

The runtime stack requires that exact new ECR image digest. It uses a new10.80.0.0/16 VPC, two verified availability zones, isolated subnets, no NAT/internet gateway or Capiro routes, worker-only private ECR/log endpoints and an S3 gateway endpoint limited to regional ECR layer objects. Security groups do not filter AmazonProvidedDNS: a DNS Firewall allows only fixed AWS image/log names, then blocks all other names. Before any task launch, explicitly set and read back DNS Firewall fail-open DISABLED; prove allowed/denied resolution and direct connection behavior on the actual task. This synthetic spike has no public-browser or model proxy yet. Fargate is Linux x86_64/non-root/read-only-root/drop-all-capabilities, with explicit workspace/tmp volumes and an IAM task role with no actions. The image must prepare UID10001 volume ownership and then prove mount permissions. Qualify Chromium sandbox without --no-sandbox, privileged/security-option workarounds or source access.

No shared CDK bootstrap is used: both stacks have bootstrapless synthesis and no assets. `npm run check:infra` synthesizes and checks security boundaries; raw synthesis uses explicit account/region/AZs rather than unresolved dummy zones. KMS log grants are constrained by literal log-group encryption context and caller ViaService. Build result writes cannot delete evidence. Before StartBuild, explicitly supply the uploaded archive's S3 VersionId as sourceVersion and bind accepted commit/archive SHA256/source version/build ID/image digest in a Codex-owned manifest. IMAGE_TAG alone does not establish that relationship.

The task runs on demand only; no ECS service, warm pool or schedule is created. Codex checks there is no active qualification task before launching one, records its ARN/deadline, monitors real output and stops failed/hung work. Results are unaccepted until independent review and reruns. G1 additionally requires trusted model proxy, durable SDK+file restoration, Office checks and Temporal topology evidence; this network/sandbox spike alone cannot pass it.

Review synthesized templates and a CloudFormation change set before executing. Verify STS account/region immediately before each mutation. Only these two named stacks are eligible. New resources are tagged Project=meri-greenfield/Environment=qualification. Buckets, images, keys and logs are retained to preserve failed-attempt evidence; clean up only the explicit resource inventory after preserving evidence. No existing Capiro resource is a teardown target. Qualification has no source data to migrate or cut over.
