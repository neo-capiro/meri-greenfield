The binding must name exact reviewed resources in account `967807252336`, region `us-east-1`; there are no default cluster, image, network, role, log, or ingress values. Synthetic binding values appear only in `manifest.test.mjs`.

The builder checks account, region, resource type and immutable image syntax. It does not treat a resource name as permission to reuse it or a reason to replace an otherwise qualified resource. The deployment owner must independently read back actual CloudFormation ownership, VPC/subnet and security-group isolation, IAM trust and actions, log permissions, image provenance, and target-group routing for the exact input identifiers before any stack action.
