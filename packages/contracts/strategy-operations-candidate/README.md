## Envelope and operation semantics

Hashes detect mismatches; a trusted owner must supply the expected identities and snapshots.

The backend resolves `applicationTarget` **before claim**, supplies its independent expected value to validation, and owns atomic comparison/application in its native write transaction. The full closed versioned target participates in `inputSha256` and is copied exactly into the result. Objective targets include tenant/client, literal Core `objective.strategy.draft` (distinct from typed operation `strategy.draft`), actual requested intent/source, canonical binding row `canonicalPlanId`, CAS `bindingVersion`, initial `epoch`, reserved canonical Strategy/project IDs, requested Objective revision/version/snapshot and explicit `create|regenerate`. No explicit replacement mode/epoch transition is allocated.
