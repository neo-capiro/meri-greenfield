# Public contract distribution dependencies

The browser validator is generated by Ajv8.20.0 and bundles its runtime helpers, ajv-formats3.0.1 and fast-deep-equal3.1.3. The unchanged Node validator also uses canonicalize5.1.0 (Apache-2.0, distributed as its own dependency). Generator-only tools are esbuild0.28.2 (MIT), json-schema-to-typescript16.0.0 (MIT) and TypeScript5.9.3 (Apache-2.0). Exact direct/transitive bytes are bound by package-lock.json. No provider or application behavior is bundled.
